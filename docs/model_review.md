# Model review status

No third-party checkpoint is integrated or automatically downloaded in v0.1.0. The deterministic
backend is fully available. The OpenAI-compatible adapter is a transport interface for a model the
operator has independently approved and started on localhost.

Before naming a default VLM, verify repository and checkpoint existence, immutable revision, license,
weight checksum and format, custom-code requirements, network behavior, expected inputs, action
vocabulary, published evaluation, and local hardware requirements. Eclipse-specific performance is
unknown. Candidate research projects from the original brief remain references, not dependencies;
their availability and licenses have not yet been audited in this repository.
